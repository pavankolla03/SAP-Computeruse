# Model Registry

This directory contains model checkpoints. Each checkpoint directory must contain:
- `README.md` — checkpoint description
- `metrics.json` — evaluation results
- `config.yaml` — training configuration
- `adapter/` — LoRA adapter weights (if applicable)
- `model/` — Full model weights (if applicable)
