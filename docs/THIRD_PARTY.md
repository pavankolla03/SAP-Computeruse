## License Scanning

Automated license scanning runs as part of CI. All third-party code must:
- Be MIT, Apache 2.0, BSD, or compatible
- Not include proprietary training data
- Be documented in this file

## Attribution

Each module that borrows from open source projects must:
1. Document what was reused
2. Document modifications made
3. Maintain attribution in source files
4. Include upstream copyright notice when required
